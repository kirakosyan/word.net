# 1.1.0 — enterprise export desktop release

Stable managed DOC/DOCX export to PDF and self-contained HTML for the documented
Windows/Linux x64 and ARM64 profile. All three packages share version 1.1.0:
`wordnet.Fonts`, `wordnet`, and optional `wordnet.Ocr`.

## Features and review fixes

- Managed PDF 1.7 and optional independently validated PDF/A-2b output, embedded
  font subsets, safe links, optional heading outlines and fixed-clock determinism.
- Self-contained HTML with inline CSS, data images, nested lists/tables and safe
  links. Optional headers/footers select the first page's applicable stories.
- Caller TTF/CFF/TTC fonts, licensed metric-compatible bundled fallbacks, kern/GPOS
  pair positioning, stories, cached fields and render-time page fields.
- Lenient geometry scaling/splitting and explicit unsupported-feature diagnostics;
  grouped diagnostic counts, conversion metrics and byte-array result overloads.
- All PR #5 review corrections: cached field containers, heading-font registration,
  independent HTML reflow, Strict revision/comment rejection, font selection and
  inheritance, JPEG termination, unsupported-image placeholders, DOCX schema order,
  decorated tabs/breaks, XPS diagnostics and cell/header scaling origins.

## Upgrade and support

`wordnet` brings managed `wordnet.Fonts` automatically. **All PDF input**, including
digital PDF import and scanned-PDF OCR, now requires an explicit reference to
`wordnet.Ocr` at version 1.1.0. Existing conversion signatures and AssemblyVersion
1.0.0.0 remain compatible. Assemblies use ordinary NuGet deployment; no GAC variant
is supplied.

Targets: `net462;net472;netstandard2.0;net8.0;net10.0`. Actual Framework 4.7.2 x64
requires the documented legacy JIT configuration. Actual Framework 4.6.2,
Android/macOS execution, complex scripts and optional tagged PDF remain outside
the qualified profile. Word pagination evidence covers the authored corpus;
arbitrary document layout parity is not guaranteed. PDF import retains editable
content but does not reconstruct the original layout.

The release gate requires all 487 conversion/OCR cases, current actual-Framework
4.7.2 source and exact-main-package runs, native Windows/Linux x64/ARM64 CI,
API/dependency/package verification, PDF/A and resource/performance gates. See
[testing](../testing.md), [minimum-runtime qualification](../minimum-runtime-qualification.md)
and the [release procedure](../releasing.md) for evidence and boundaries.
