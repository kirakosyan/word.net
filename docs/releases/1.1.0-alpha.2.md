# 1.1.0-alpha.2 — enterprise export review fixes

This preview retains the managed PDF/HTML export introduced in alpha.1 and fixes
the 15 findings on PR #5. The package set is `wordnet.Fonts`, `wordnet`, and optional
`wordnet.Ocr`, all at 1.1.0-alpha.2. AssemblyVersion remains 1.0.0.0.

- Cached DOC/DOCX fields keep their original paragraphs and table cells, including
  nested field results and hyperlinks.
- Numbered headings resolve label fonts before fixed layout snapshots the font
  collection. Catalogs prefer the requested regular/bold weight over filename
  order, and non-Latin font hints preserve inherited Latin families.
- HTML retains cached page-field text without invoking PDF layout. Optional
  headers/footers select the variants for the first page of the first section.
- Strict again rejects tracked revisions and comments. BestEffort/Lenient emit
  explicit fidelity warnings while retaining the accepted text.
- Byte-array PDF/HTML export overloads now expose `out ConversionResult` for
  diagnostics and metrics. Existing byte-only and stream signatures remain.
- JPEGs may contain trailing padding or motion-photo data after EOI. Metadata
  byte patterns cannot hide missing image termination. Unsupported logo formats
  receive diagnosed placeholders in BestEffort/Lenient.
- DOCX numbering/tab properties serialize in schema order, decorated tabs/breaks
  retain their appearance, cell tab stops and scaled lines keep the correct
  origin (including indented continuation lines and scaled header tables), and
  XPS no longer reports retained stories/fields/fonts as losses.

The regression suite adds 36 cases, bringing the required suite to 487 cases per
runtime. Current validation evidence and release prerequisites are recorded in
[testing](../testing.md) and [releasing](../releasing.md). Earlier alpha.1 runtime,
performance, and PDF/A reports describe that revision and do not qualify this one.

PDF input and OCR require `wordnet.Ocr` at the same version. The core supports
`net462;net472;netstandard2.0;net8.0;net10.0`; actual .NET Framework 4.6.2,
Android/macOS execution and tagged PDF remain outside the qualified profile.
Actual Framework 4.7.2 requires the documented legacy JIT configuration.
