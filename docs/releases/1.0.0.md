# 1.0.0

First stable release of the documented Windows/Linux desktop conversion profile.
The library is independently authored and MIT licensed, with explicit diagnostics for
features outside that profile. Android and macOS are deferred for this release.

- All 28 DOC/DOCX conversion directions, XPS output and editable English printed-text
  OCR for scanned and mixed PDFs.
- Next-page section geometry, paragraph spacing/indents/keep controls, multi-paragraph
  table cells, horizontal/vertical merges, repeating headers and long-row pagination.
- Optional OCR rotation/deskew and separately enabled two-column reading order; default
  OCR preserves native line and paragraph order. Recognition supports cancellation.
- Defensive document parsing, bounded input/output/expansion, staged destinations and
  explicit strict/best-effort fidelity handling. Hard deadlines require host isolation.
- 348 shared conversion/OCR/regression cases, independent schema/format readers and
  layout/OCR fixtures, isolated mutation and concurrent resource campaigns, and exact
  NuGet/explicit .NET Standard asset validation on native Windows/Linux x64 and ARM64.
- Public API compatibility across `net472;netstandard2.0;net8.0;net10.0` and against
  published alpha.9; runtime dependencies are unchanged.

Actual .NET Framework 4.7.2 x64 requires `<useLegacyJit enabled="1" />` in the host
application's runtime configuration. Default-JIT 4.7.2 operation is unsupported because
of a reproduced runtime code-generation defect. Framework 4.8.1 uses default settings.
The library does not change host configuration. Tesseract 5 and English data must be
supplied locally, matching the process architecture.

This release does not promise original Word pagination or unrestricted rich-document
fidelity. Password protection, tracked changes/comments, editable charts/equations,
arbitrary fonts, nested tables, handwriting and non-English OCR remain outside the
profile. Android, macOS, trimming and AOT are unqualified.
