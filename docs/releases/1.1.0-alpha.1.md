# 1.1.0-alpha.1 — enterprise export preview

This source/local-package preview adds managed DOC/DOCX → PDF and self-contained
HTML export, default/first/even header/footer stories, evaluated/preserved fields,
caller TTF/CFF font streams/directories/TTC catalogs, OFL fallback fonts, legacy/GPOS pair
kerning, justified/distributed alignment, aligned tabs, nested DOCX/HTML tables,
cell decoration in HTML, GIF/BMP conversion, accepted revisions, current content
controls, grouped diagnostics, metrics and deterministic output with a fixed clock.
PDF options add hierarchical heading outlines, compression controls and independently
validated PDF/A-2b. PNG prediction/alpha, Unicode DOC metadata and styled hyperlink
field results are retained. Adjacent merge-engine runs coalesce before kerning.

`FidelityMode.Lenient` adds deterministic scaling/splitting/flattening policies.
Notes become numbered end text with a warning; anchored images become inline;
unsupported vector images get placeholders. Strict still rejects detected losses.

The new **wordnet.Ocr** package is required for PDF input and OCR. Existing conversion
signatures and `EnglishOcrOptions` remain in core; callers upgrading PDF import must
add the companion package at the same version. `wordnet.Fonts` is a managed core
dependency. All five targets build, including new net462 assets; actual .NET 4.6.2
execution has not been qualified. AssemblyVersion stays 1.0.0.0; assemblies remain
unsigned under the NuGet-only deployment decision. Nothing has been published.

See [enterprise audit](../enterprise-audit.md) for the issue #4 acceptance mapping.
P1 features outside the renderer's profile use the explicitly diagnosed deterministic
Lenient degradation allowed by the issue's definition of done. Positioned shapes,
page-bottom footnotes, advanced themes/columns/lists and complex shaping are not
claimed as fully rendered. Tagged PDF remains optional/unimplemented.

Independent Microsoft Word 16.0 / build 16.0.20430 measurements are recorded for
38 authored inputs; wordnet matches all 36 business-category page counts exactly.
The two hostile-size stress inputs are categorized separately. These are page-count
checks on a narrow authored corpus, not an arbitrary-template visual fidelity claim.
The 451-case suite retains all original directions/OCR. The single-core ten-page
image/table fixture measured 75.796 ms median with a 40.1 MB conservative managed
upper bound; CI rejects >25% comparable regressions. All 38 archival corpus outputs
pass pinned veraPDF 1.30.2. No customer document or output was added to the solution.
