# 1.2.1 — NuGet README presentation

Patch release preparation for `wordnet`, `wordnet.Fonts` and `wordnet.Ocr`, all at
1.2.1. Publication is pending; 1.2.0 remains the last verified public release.

The README header uses six consistent Markdown badges for NuGet version, downloads,
main-branch build, MIT license and Windows/Linux x64/ARM64 support. Raw HTML image
sizing is removed because NuGet disables HTML in its Markdown renderer. Images use
NuGet's allowed `img.shields.io` host; each badge has readable alternative text.
The Windows mark is an inline SVG logo parameter inside the remote image URL,
so it does not depend on a removed logo alias or expose raw HTML in the document.

NuGet freezes a package's README when that version is published; correcting the
1.2.0 page requires a new package version. See
[NuGet README guidance](https://learn.microsoft.com/nuget/nuget-org/package-readme-on-nuget-org).
All three packages share the corrected README. The installation example selects
the latest public version without hard-coding a stale release number.

Documentation links in the README use absolute GitHub URLs. NuGet clears relative
file links during sanitization; internal section anchors remain valid. The source
README therefore works in both GitHub and the package gallery.

Conversion, editing/templates, diagnostics, font resources, native providers and
the [bounded 1.2.0 profiles](1.2.0.md) retain their existing behavior. Package metadata
and PDF producer version become 1.2.1; AssemblyVersion remains 1.0.0.0, all five
core/OCR assets remain, and API compatibility is checked against published 1.2.0.
The required suite remains 829 cases. The same PR #43 also updates
CI actions to Node.js 24 and fixes SDK selection.
