# 1.5.0 — document workflows, review and drawings

`wordnet`, `wordnet.Fonts` and `wordnet.Ocr` advance together to 1.5.0. Use matching
versions. This release delivers roadmap #102 through PRs #131, #133–#137.

## Changes

- Corrected DOCX defaults, paragraph-mark metrics, managed implicit table sizing and footnote separators/continuation.
- Typed custom-property fields, deterministic numeric/date formatting, bounded nested IF trees and STYLEREF running headers.
- Opt-in checkbox/list/date/rich-text controls and explicit bounded local XML binding.
- Mixed and master-detail report regions, prepared count/sum cross-tabs and caller-supplied fragments.
- Formatting revisions, unambiguous paragraph moves, matching-section comparison and plain header/footer text revisions.
- Quarter-turn and shrink-to-fit text boxes, bounded linked chains and editable line/ellipse/rounded-rectangle vectors.

The [capability matrix](../roadmap-102-capability-matrix.json) links the exact profiles
and independent acceptance tests. Review follow-ups preserve mirrored Word formatting
metadata, distinguish explicit linked-box heads, share admission rules and strengthen
cross-feature output assertions.

## Compatibility and limits

Public APIs remain compatible with published 1.4.0; AssemblyVersion stays 1.0.0.0.
Core/OCR retain `net462;net472;netstandard2.0;net8.0;net10.0`. Default DOCX metrics
and corrected layout can change pagination; verify representative documents when upgrading.
Typed controls and review preservation remain opt-in. PDF input requires matching
`wordnet.Ocr`; English OCR requires local Tesseract and language data.

The new drawing profiles require ordinary managed fixed output. Tagged/archive PDF,
native typography, ambiguous chain ownership, cross-section/rotated chains, arbitrary
shape effects and unsupported revision histories fail explicitly. Actual Framework
4.7.2 x64 retains its documented legacy-JIT requirement. Actual 4.6.2, Android/macOS
release support, additional OCR languages and encryption/signatures remain outside scope.
Independent reference differences remain visible under unchanged fidelity thresholds.
The separate planning proposal in #99 is not delivered by this release.

## Qualification and publication

See the [P6 record](../roadmap-102-p6-qualification.md) for dated local/historical evidence.
Release gates require successful push CI for the exact final-main commit, all desktop
source/package/Standard lanes, actual Framework 4.7.2 source/package guests, independent
validators, performance/resource checks and immutable archive inspection. The publishing
workflow retests the same artifact before NuGet upload.

The [release page](https://github.com/kirakosyan/word.net/releases/tag/v1.5.0) records
the final commit, CI/artifact hashes, runtime/cleanup receipts, publication run and
public-package payload verification. Merging these notes alone does not establish publication.
