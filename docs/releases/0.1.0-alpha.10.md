# 0.1.0-alpha.10 — unpublished candidate

Superseded by [1.0.0](1.0.0.md); this candidate version was not published. The notes
below retain its development-stage scope and qualification status.

This candidate expands the supported fidelity profile and production qualification.
It is not a stable release or a production-readiness claim. Actual Framework 4.7.2 and
Android API 21 qualification remain open; macOS is deferred.

- Retain next-page section geometry, empty final sections, paragraph spacing/indents,
  inherited line rules and keep controls through Word and fixed-page output.
- Retain multiple paragraphs and horizontal/vertical merges in Word/EPUB cells;
  repeat table headers and split long ordinary rows in PDF/XPS. Oversized merged or
  non-splitting groups fail explicitly.
- Add optional English OCR orientation correction/deskew, conservative two-column
  reading order and native recognition cancellation. Existing constructor signatures
  remain compatible and orientation correction remains opt-in.
- Add independent layout and OCR reference data, 301 shared tests, isolated malformed-input
  and resource campaigns, and exact-package/explicit Standard-asset CI validation.
- Normalize malformed DOC/PDF provider failures while preserving destination streams.
  Document host isolation, resource budgets and API/versioning policy.

All four library targets remain `net472;netstandard2.0;net8.0;net10.0`. Runtime dependencies
are unchanged. Binary API validation uses the published alpha.9 baseline. Review
[the fidelity profile](../document-fidelity.md), [qualification gates](../production-readiness.md)
and [build-specific evidence](../testing.md) before deployment.
