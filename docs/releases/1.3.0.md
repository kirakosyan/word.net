# 1.3.0 — reporting, document exchange, review and editable objects

Published on 2026-10-20 as `wordnet`, `wordnet.Fonts` and `wordnet.Ocr` 1.3.0,
versioned and qualified together. The stable [v1.3.0 release](https://github.com/kirakosyan/word.net/releases/tag/v1.3.0)
and annotated tag resolve to commit `c723fb8aa4ed70fda5562da7f472e6fef54740b7`.
Public 1.2.1 is the preceding README presentation release.

The release includes the P0 adoption work from PR #83: expanded
independent business-document fixtures and executable invoice/report recipes.

This release adds the bounded P1 reporting/columns, DOCX ↔ ODT and review workflows
from PR #85, and the P2 chart/equation and typography profile from PR #86:

- Detached report preprocessing, contiguous body repeats and explicit column layout.
- ODF 1.3 package exchange with DOCX; opt-in plain-text revisions, classic comments,
  explicit decisions/recording and Unicode-aware matching-structure comparison.
- Preserved editable clustered-column/ordinary-line charts and genuine OMML,
  managed chart vectors, OpenType MATH layout and immutable add/update/remove APIs.
- Opt-in Unicode 17 bidi and ordinary Hindi Devanagari, with separately qualified
  logical text and tagged PDF/PDF-UA-1 output.

The object review fixes preserve nested row order, join radical rules to their
glyphs, stop script shrinking at scriptscript size, distinguish control-character
formatting, retain object ascent in exact-spaced paragraphs, and support atomic
content/description updates and removal of API-created empty object paragraphs.
Permissive conversion diagnoses omission of valid unsupported objects; strict
conversion and session loading reject that loss. Unsafe or malformed input still
fails in every mode. See the [complete profile](../p2-objects-typography.md),
[ODT limits](../odt.md), [review limits](../review-workflows.md) and
[reporting profile](../report-preprocessing.md).

Password encryption/decryption and DOCX/PDF signatures are cancelled and absent.
General chart types, arbitrary equations, native stories and unqualified
object/native/accessibility combinations remain unsupported. OCR remains English
printed text. Android and macOS remain outside the desktop release scope.
Actual Framework 4.7.2 x64 requires the documented legacy JIT configuration;
Framework 4.6.2 compatibility metadata is not runtime qualification.

Core/OCR targets remain `net462;net472;netstandard2.0;net8.0;net10.0` with matching
public APIs and AssemblyVersion 1.0.0.0. Package API validation compares against
published 1.2.0. Development MATH/Devanagari fonts, fixtures and qualification
tools are excluded from the packages.

The required conversion/OCR suite contains 1,050 cases without skips. The completed
[exact-main CI 39489107294](https://github.com/kirakosyan/word.net/actions/runs/39489107294)
qualified native Windows/Linux x64/ARM64 source and exact-package runs, explicit
.NET Standard fallback, actual Framework 4.7.2 source/package guests and independent
object/typography checks. [Publication run 39494674611](https://github.com/kirakosyan/word.net/actions/runs/39494674611)
retested immutable artifact `12295407881` before publishing; its nine TRX reports
recorded 9,450 individual passes with zero failures or skips. These are recorded
release results, not new executions during documentation reconciliation.

The [completed release ledger in roadmap #45](https://github.com/kirakosyan/word.net/issues/45)
records artifact hashes, minimum-runtime receipts, independent checks and public
DLL verification. All eleven public DLLs and original archive entries matched the
qualified artifact; only repository signatures were added. Fresh public consumers
also ran chart editing and DOCX/PDF exports on .NET 8/10.
